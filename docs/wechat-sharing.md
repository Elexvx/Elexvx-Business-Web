# 官网分享与微信卡片

## 已实现

- 全站分享入口：复制正式链接、浏览器系统分享、生成和下载 PNG 分享卡片。
- 分享卡片在浏览器本地生成，包含封面、标题、摘要和正式网址二维码；不上传用户信息。微信内可长按保存图片。
- 每页静态 HTML 包含 Open Graph、Twitter 标题/摘要/封面以及 canonical URL。活动、研究、案例、新闻采用各自封面，其他页面采用默认品牌封面。

## 技术边界

本站不提供公众号 JS-SDK 签名接口，也不在浏览器中加载 `wx.config`。因此项目不保存或转发公众号 AppID、AppSecret、`access_token` 或 `jsapi_ticket`，部署也不依赖 `/api/wechat/signature`。

微信内分享使用页面自身的标准元数据和微信右上角菜单；需要控制内容时，使用站内生成的图片卡片或复制正式链接。网页元数据不能保证微信自动显示指定卡片，最终效果仍需在真实微信客户端验收。

## 验证

- `npm run build`：检查中英文静态页面、canonical 和分享元数据。
- `npm test`：运行分享卡片及其他项目测试。
- 部署后分别在 iOS 和 Android 微信打开正式文章，使用右上角菜单发送给朋友或朋友圈，核对标题、摘要、图片及链接；也可在微信内长按保存站内生成的分享卡片。
