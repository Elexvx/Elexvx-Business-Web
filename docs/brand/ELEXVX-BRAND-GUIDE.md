# Elexvx Logo 2.0

## 核心设计

新标识将 `E` 与 `X` 共构为一个几何符号：三条横向骨架代表多元业务在同一品牌下汇聚，交叉的 `X` 代表跨市场连接与持续探索。向前的切角保留行动感，同时删除旧标识中的尾流、渐变、描边和斜体变形。

## 品牌资产

- `elexvx-logo.svg`：品牌蓝主标志，透明背景
- `elexvx-symbol.svg`：独立 EX 图形标，透明背景
- `elexvx-logo-black.svg`：单色黑版本
- `elexvx-logo-white.svg`：反白版本，透明背景
- `elexvx-logo-reverse.svg`：反白效果预览，包含品牌蓝底色

所有字形均已转为 SVG 路径，不依赖外部字体。

## 颜色

- Elexvx Cobalt：`#0B3EA8` / RGB `11 62 168`
- Black：`#111111` / RGB `17 17 17`
- White：`#FFFFFF` / RGB `255 255 255`

印刷生产前应由印厂依据纸张、油墨和工艺进行打样；不要直接以屏幕 RGB 颜色代替最终专色确认。

## 尺寸与留白

- 主标志的数字端最小宽度为 `96px`。
- 独立图形标的数字端最小尺寸为 `16px`；印刷端建议不小于 `6mm`。
- 四周至少保留一条图形横杠高度的净空。
- 小尺寸、头像、应用图标和 favicon 统一使用独立图形标。

## 使用规则

- 浅色背景使用品牌蓝或黑色版本。
- 深色背景使用透明底白色版本。
- 单色印刷、雕刻、压印和传真使用黑色或反白版本。
- 不添加渐变、描边、阴影、发光或其他装饰。
- 不拉伸、不旋转、不改变字标与图形标的相对比例。
