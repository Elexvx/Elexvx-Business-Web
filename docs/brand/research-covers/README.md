# 研究封面

这组 5 张封面使用内置 image_gen 作图工具生成，沿用参考图的柔焦色块、磨砂折射与细颗粒质感。各篇以独立配色和光线方向区分，不叠加标题、图标或芯片示意图。

页面读取 `public/visuals/research/color-covers/` 下的 720 × 720 WebP，由 `content/site/research.json` 的 `cover` 字段统一指定。首页的中英文静态片段由 `scripts/generate-home.tsx` 同步生成；研究列表、相关文章和分享元数据使用同一数据源。旧渐变文件保留供其他页面继续使用。
